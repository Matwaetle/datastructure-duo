A7의 lower_bound 보기 
def lower_bound(a, x):
    lo, hi = 0, len(a)               # 후보 범위 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo

(이름, 점수) 쌍이 점수 오름차순으로 놓여 있어요. 쌍 전체가 아니라 점수만 비교하고 싶을 땐 key=에 점수를 꺼내는 함수를 줘요. lambda s: s[1]은 s의 두 번째 값을 꺼내는 이름 없는 함수예요.

s = ("A", 70)일 때 s[1]은 무엇일까요?
