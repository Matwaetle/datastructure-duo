이론 정리 · 배경 지식

이 상자에서는 활동에 필요한 말과 도구를 미리 읽어요. 활동의 답이나 오늘의 일반화는 여기 없어요. 그건 활동하면서 직접 찾아요.

  • 동적 계획법(DP)은 큰 문제의 답을 작은 문제의 답으로 나타내는 설계 방법이에요. 한 번 구한 작은 문제의 답은 저장해 두고 다시 써요.
  • 탐욕 알고리즘(Greedy)은 단계마다 지금 가장 좋아 보이는 선택 하나를 하고, 그 선택을 바꾸지 않는 방법이에요. 예: 시험 시간이 모자랄 때 가장 쉬운 문제부터 풀어요.

핵심 용어

  • 상태: 작은 문제 하나를 구별하는 값이에요(예: 어떤 n). 전이(점화식): 한 상태의 답을 더 작은 상태의 답으로 나타내는 규칙이에요. 기저 상태: 더 쪼갤 수 없어서 답을 바로 아는 상태예요.

작은 예 · 1부터 n까지의 합

T(n) = 1 + 2 + … + n 을 T(n) = T(n−1) + n, T(0) = 0 으로 나타내요. 기저 상태는 T(0)이에요. 아래 두 코드는 같은 값을 다른 방향으로 구해요. 첫째는 재귀로 내려가며 구한 답을 dict에 적어 둬요. 둘째는 작은 n부터 반복문으로 표를 채워요.

# 재귀로 내려가며, 구한 답은 memo(dict)에 적어 둔다.
def tri(n, memo):
    if n == 0:                 # 기저 상태
        return 0
    if n in memo:              # 이미 구한 답이면 그대로 쓴다.
        return memo[n]
    memo[n] = tri(n - 1, memo) + n
    return memo[n]

print(tri(4, {}))              # 10
# 작은 n부터 표 t를 순서대로 채운다.
t = [0] * 5                    # t[0] = 0 (기저)
for i in range(1, 5):
    t[i] = t[i - 1] + i
print(t)                       # [0, 1, 3, 6, 10]

파이썬 도구

  • dict: k in memo로 있는지 묻고 memo[k]로 꺼내는 표예요. 평균적으로 한 번에 찾아요.
  • 리스트 표: [0] * (n + 1)로 0번부터 n번까지 칸을 만들어요. 그리고 for i in range(1, n + 1)로 순서대로 채워요.
  • 무한대: 만들 수 없는 경우는 INF = float('inf')로 나타내요. 어떤 수와 비교해도 INF가 더 커요. 그래서 min(3, INF)는 3이에요.
  • functools.lru_cache: 함수 위에 @lru_cache(maxsize=None)를 붙이면 인자별 결과를 자동으로 기억해요.
  • 재귀 깊이: 파이썬은 재귀 호출을 약 1000겹까지만 허용해요. 큰 n을 재귀로 풀면 오류가 날 수 있어요.

복잡도 표기 읽는 법

  • O(n)은 입력 크기 n이 커질 때 일의 양이 n에 비례해 늘어난다는 뜻이에요. O(n²)은 n이 2배가 되면 일이 약 4배가 돼요. O(2ⁿ)은 n이 1 늘 때마다 일이 2배가 돼요.
  • 표 크기만큼 메모리도 써요. 시간을 줄이는 대신 저장 공간을 쓴다는 점도 함께 기억해요.
