이론 정리 · 배경 지식
  • 탐색(순회)이란: 그래프의 한 노드에서 출발해 간선으로 이어진 이웃으로 한 걸음씩 나아가며 노드를 살펴보는 일이다. 길 찾기, 몇 단계 만에 닿는지 세기, 이어진 덩어리 세기가 모두 이 일에 속한다. 노드 하나를 살펴보는 것을 방문이라고 한다. 오늘은 “어느 이웃을 어떤 순서로 방문할 것인가”를 직접 알아낸다.
  • 그래프와 이웃: 점(노드)과 선(간선)으로 이루어진다. 파이썬에서는 딕셔너리로 노드마다 이웃 목록을 적는다(10주차). 한 걸음에 갈 수 있는 노드의 모임이 그 노드의 이웃이다.
  • 2차원 격자: 미로나 지도는 문자열 목록으로 나타내고 grid[행][열]로 한 칸을 읽는다. 위·아래·왼쪽·오른쪽 네 칸이 이웃이며, 이동량을 (행 변화, 열 변화) 쌍의 목록으로 적어 두고 반복한다. 가장자리 칸은 이웃이 격자 밖에 있을 수 있으므로 범위 검사가 필요하다.
  • 방문 기록: 이미 본 노드를 적어 두는 곳이다. 집합(set)은 “들어 있는가” 검사 x in seen이 빠르다.
  • 컨테이너: 앞으로 볼 노드를 잠시 담아 두는 자료구조이다. 5주차에서 배운 두 가지를 떠올린다. 스택은 가장 나중에 넣은 것을 먼저 꺼내고, 큐는 가장 먼저 넣은 것을 먼저 꺼낸다. 파이썬에서 스택은 list의 append와 pop(), 큐는 collections.deque의 append와 popleft()로 쓴다.
  • 재귀와 호출 스택: 함수가 자기 자신을 부르면 부른 함수가 끝날 때까지 호출 기록이 쌓였다가 거꾸로 사라진다(8주차). 이 기록이 쌓이는 곳이 Call Stack이다.
  • 시간복잡도 읽는 법: 입력 크기에 따라 작업 횟수가 어떻게 늘어나는지를 O(…)로 적는다. O(N)은 “개수 N에 비례해 늘어난다”, O(1)은 “개수와 상관없이 한 번에” 걸린다는 뜻이다. 그래프의 노드 수는 V, 간선 수는 E, 격자의 행·열 수는 R, C로 적는다.

작은 예 1 · 컨테이너 연산 (활동 데이터와 다른 값이다.)

from collections import deque
box = deque(["x", "y"])
box.append("z")
print(box)               # deque(['x', 'y', 'z'])
print(box.popleft(), box)  # x deque(['y', 'z'])
print(box.pop(), box)      # z deque(['y'])
print(len(box) == 0)       # False

작은 예 2 · 그래프 딕셔너리와 방문 기록

g = {"P": ["Q", "R"], "Q": ["P"], "R": ["P", "S"], "S": ["R"]}
print(g["R"])                  # ['P', 'S']
for nb in g["R"]:
    print("R의 이웃:", nb)     # R의 이웃: P / R의 이웃: S
seen = set()
seen.add("P")
print("P" in seen, "Q" in seen)  # True False

작은 예 3 · 격자의 네 이웃과 범위 검사

grid = ["..#",
        "#.."]
R, C = len(grid), len(grid[0])
print(R, C, grid[1][2])        # 2 3 .
DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]
r, c = 1, 1
for dr, dc in DIRS:
    nr, nc = r + dr, c + dc
    if 0 <= nr < R and 0 <= nc < C:
        print((nr, nc), grid[nr][nc])
    else:
        print((nr, nc), "격자 밖")   # (0, 1) . / (2, 1) 격자 밖 / (1, 0) # / (1, 2) .

작은 미로 보기

입구에서 출구까지 가는 길을 찾는다. 길이 셋 이상 만나는 곳이 갈림길이다.

입구 ─ P ─ Q ─ 출구
       │
       R  (막힌 길)

그림에서 갈림길은 어디일까?

P에는 입구, Q, R 세 길이 만난다.

갈림길에서 고르기

P에서 R로 들어갔다가 막다른 길이었다고 하자. 내 말로 써 보자.

갈림길에서 어느 쪽으로 가고, 막히면 어떻게 하겠는가?

지나온 곳을 또 가면

X, Y, Z 세 사람이 서로 모두 친구이다. 소문이 X에서 Y, Y에서 Z로 갔다.

가 본 곳을 적어 두지 않고 Z에서 다시 X로 가고, Y로 가고… 계속 가면 어떻게 될까?

같은 곳을 또 가기 때문에 끝나는 때를 알 수 없다.

소문은 몇 단계

소문이 A에서 B로, B에서 C로 퍼졌다. 시작한 A는 0단계이다.

C에게 소문은 몇 단계 만에 닿았을까?

A-B, B-C로 두 번 전해졌다. 단계는 지나온 친구 관계(간선)의 수이다.

활동을 마친 뒤 열어 확인한다 · 세 사례의 공통점과 말뜻
  • 세 사례는 모두 “지금 있는 곳에서 이웃으로 한 걸음씩 나아가는” 문제이다. 갈림길에서 어느 이웃을 먼저 볼지 정하는 규칙이 필요하다.
  • “몇 단계”는 소문이 전해진 횟수, 곧 시작한 사람에서 그 사람까지 지나는 친구 관계(간선)의 수이다.
  • 이미 지나온 곳을 또 가면 같은 곳을 빙빙 돌아 끝나지 않거나 시간을 낭비한다. 그래서 가 본 곳을 적어 둘 곳이 필요하다.
  • 어느 이웃부터 가느냐에 따라 지나는 길과 순서가 달라진다. 이 차이를 A2부터 손으로 따라가며 확인한다.

A2 · 컨테이너 두 가지로 손 탐색하기1차시 · 14분 · 개인

작은 그래프 X 보기

컨테이너는 앞으로 볼 노드를 담아 두는 곳이다. 스택은 맨 위(오른쪽 끝)에서, 큐는 맨 앞(왼쪽 끝)에서 꺼낸다. 시작 노드를 넣고 ‘꺼낸다 → 방문한다 → 안 가 본 이웃을 목록 순서로 넣는다’를 컨테이너가 빌 때까지 되풀이하며, 방문한 차례가 방문 순서이다.

X: [Y, Z]   Y: [X]   Z: [X]       스택 규칙, 시작 X

단계 3      꺼냄 Y (방문)  → 컨테이너 [ ]
방문 순서   X, Z, Y

큐 규칙으로 X를 돌면 방문 순서는?

X, Y, Z이다. 스택 규칙의 X, Z, Y와 둘째 노드가 다르다.

A3 · 재귀로 돌아보기: 호출이 쌓이는 모습1차시 · 13분 · 개인

호출이 쌓이는 모습

함수가 시작되는 때를 enter, 끝나 돌아오는 때를 exit라 한다. 호출은 Call Stack에 쌓이고, 끝나면 맨 위부터 사라진다. 이 스택은 파이썬이 호출마다 자동으로 관리한다. Call Stack 칸은 아래에서 위로 [P, Q]처럼 쓴다.

P: [Q]   Q: [P, R]   R: [Q]     dfs(P)를 따라 간 모습

순서  사건      Call Stack(아래부터)

 4   exit R    [P, Q]

순서 5에서 exit Q를 한 직후, Call Stack의 맨 위는?

Q가 끝나 사라지면 아래에 있던 P가 맨 위가 된다.

이 Call Stack은 누가 만들어 주는가?

재귀 호출이 있으면 파이썬이 알아서 쌓고 치운다.

G1을 재귀로 따라 가기

시작 A에서 아래 의사코드를 따라 간다. 표는 10줄이 모두 필요하며, 사건과 Call Stack 두 가지만 쓴다.

A ─ B
│   │

A: [B, C]   B: [A, D]   C: [A, D]   D: [B, C, E]   E: [D]
def dfs(u):          # 의사코드
    visited에 u 추가, order에 u 기록
    for 이웃 v in (u의 이웃 목록 순서):

재귀는 목록의 첫 이웃 A로 바로 들어간다. 스택 규칙은 A, B를 모두 넣고 마지막에 넣은 B를 먼저 꺼냈다.

이 경로 S-A-T의 간선 수는?

오늘부터 큐 규칙을 너비 우선 탐색(BFS), 스택 규칙과 재귀 규칙을 깊이 우선 탐색(DFS)이라고 부른다. 이름일 뿐 어느 쪽이 더 좋다는 뜻은 아니다.

A2에서 큐 규칙으로 돌아 얻은 방문 순서는 어느 탐색의 것일까?

큐 규칙이 BFS이다. 스택 규칙과 재귀는 DFS이다.

새 시작 노드로 따라 하기

G1에서 시작 노드를 D로 바꿔 큐 규칙(BFS)을 처음부터 따라 해 보자. 시작 D가 1번째일 때 A는 몇 번째로 방문될까?

A ─ B
│   │
C ─ D ─ E        F

A: [B, C]   B: [A, D]   C: [A, D]   D: [B, C, E]   E: [D]

버려진 줄은 방문 순서에 세지 않는다.

헷갈린 점 쓰기

시작 D에서 큐 규칙의 방문 순서는 D, B, C, E, A이므로 A는 5번째이다. D를 방문하며 B, C, E를 넣고, B를 방문하며 A를 넣고, C를 방문하며 A를 한 번 더 넣는다. A는 큐에 두 번 들어가지만 방문은 처음 꺼낸 때 한 번이고, 버려진 줄은 순서에 세지 않는다.
