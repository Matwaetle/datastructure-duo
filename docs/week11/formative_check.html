Q2 · 방문 순서와 경로 추적

무방향 그래프 F의 간선은 (P,Q) (P,R) (Q,S) (R,S) (R,T) (S,U) (T,U)이고, 이웃 목록은 아래와 같아요. 이웃 순서는 목록 순서예요.

P: [Q, R]   Q: [P, S]   R: [P, S, T]   S: [Q, R, U]   T: [R, U]   U: [S, T]

시작 P에서 네 가지를 써요. 큐 규칙(BFS)의 방문 순서, P→U의 최소 간선 수, 이웃 목록 순서대로 재귀 DFS를 했을 때 처음 찾은 P→U 경로와 그 간선 수예요.

쓰는 법 방문 순서 칸은 노드 이름만 쉼표로(예: P, Q, R) 써요. 간선 수 칸은 숫자 하나만 써요. 경로 칸은 시작 노드부터 끝 노드까지 하이픈으로 이어서(예: A-B-C) 써요.

Q3 · visited 함정

아래 코드를 F에서 시작 P로 실행했을 때 출력되는 방문 순서를 써요. 그리고 중복이 생기는 이유와 고치는 방법을 한 문장씩 써요.

from collections import deque

# F: 인접 리스트(Q2와 같은 그래프). 이웃 순서는 목록 순서이다.
F = {"P": ["Q", "R"], "Q": ["P", "S"], "R": ["P", "S", "T"], "S": ["Q", "R", "U"], "T": ["R", "U"], "U": ["S", "T"]}

def bfs_nostart(g, start):                   # 시작 상태: 큐 [start], visited는 비어 있다
    q = deque([start])
    visited = set()
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            if v not in visited:
                visited.add(v)
                q.append(v)
    return order

print(bfs_nostart(F, "P"))

쓰는 법 출력된 리스트를 대괄호까지 그대로 써요(예: ['X', 'Y']).

쓰는 법 한 문장. 중복이 생기는 이유를 써요.
