  • 동전 최소 개수를 표 dp로 구해요. 만들 수 없는 금액이면 −1을 돌려줘요.
  • dp[a]: a원을 만드는 최소 동전 개수예요.
  • INF: ‘만들 수 없음’을 뜻하는 아주 큰 값이에요.
def dp_t2(coins, amount):
    dp = [0] * (amount + 1)
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    return dp[amount] if dp[amount] != INF else -1

def make_grid_t3(R, C):
    dp = [[0] * C] * R
    dp[0][0] = 1
    return dp
