25번에서 11번으로 줄어요. 예측·실제·원인은 활동지 2부 A10에.

  • 동전 최소 개수를 표 dp로. 만들 수 없으면 −1
  • INF = ‘만들 수 없음’ 뜻의 아주 큰 값
def dp_t2(coins, amount):
    dp = [0] * (amount + 1)
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    return dp[amount] if dp[amount] != INF else -1

print("T2", dp_t2([1, 3, 4], 6), dp_t2([5, 7], 3))
