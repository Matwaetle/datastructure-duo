while 반복이 끝났을 때 lo와 hi의 관계는 무엇인가요?

조건 lo < hi가 거짓이 되는 순간 lo와 hi가 같아져요.

def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo

코드의 두 줄 lo = mid + 1과 hi = mid의 이유각각 한 문장으로 쓰세요. 탐색 범위는 [lo, hi)예요.
