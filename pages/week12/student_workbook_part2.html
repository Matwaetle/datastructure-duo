반복이 끝났을 때 lo와 hi는 어떻습니까?

조건이 거짓이 되는 순간 둘이 같아집니다.

def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo
