• A2에서 배운 ‘가운데 값과 비교하여 절반씩 버리기’로 경계 위치를 찾습니다.
lower bound처음으로 x 이상이 나오는 자리
upper bound처음으로 x 초과가 나오는 자리
  • 두 값 모두 원소 값이 아니라 칸 번호(인덱스)입니다.

같은 B에서 x = 6일 때 lower bound는 무엇입니까?

6은 인덱스 3에 있고, 그 앞의 값은 모두 6보다 작습니다.

x = 6일 때 upper bound는 무엇입니까?

6보다 큰 첫 값 9가 인덱스 4에 있습니다.

  • [lo, hi) = lo 칸은 포함하고, hi 칸은 포함하지 않음
  • 처음: lo = 0, hi = len(B) = 5
  • mid = (lo + hi) // 2 (// 는 몫)

B[mid] = 4 < 9. 처음으로 9 이상이 나오는 위치는 mid의 어느 쪽입니까?

mid까지는 모두 9보다 작으므로 답은 3번 칸 이후입니다.

후보가 [3, 5)로 줄면 mid=4, B[4]=9 = x입니다. 답은 무엇입니까?

B[3]=6 < 9 이므로 mid 자신(4번)이 답입니다. 연습 편집기에서 lo, hi = 3, 5 로 바꾸어 확인하십시오.

N리스트 길이목표 비용만족할 수 있는 비교 횟수

코드를 작성하기 전에 계획을 한 줄로 쓰십시오후보를 줄이는 방법과 만족할 수 있는 비교 횟수

DUP[1, 3, 3, 3, 5, 7, 7, 9, 12, 12, 12, 12, 15]SORTED[2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
  1. ①②③ 범위와 반복
    lo, hi = ①, ②리스트 전체를 덮는 [lo, hi)
    while ③:후보가 하나라도 남은 동안
  2. ④⑤⑥ 갈림길 (lower_bound)
    ④ 답이 mid 오른쪽→lo = ⑤ mid는 답이 아님
    else→hi = ⑥ mid 자신이 답일 수 있음
  3. ⑦ upper_bound
    if ⑦: lo = mid + 1구조는 같고 ‘초과’에 맞게 비교 조건만 다름
def lower_bound(a, x): ...   # 처음으로 x 이상인 자리, 없으면 len(a)
def upper_bound(a, x): ...   # 처음으로 x 초과인 자리, 없으면 len(a)

B = [2, 4, 4, 6, 9]
print(lower_bound(B, 4), upper_bound(B, 4))   #=> 1 3
print(lower_bound(B, 10))                     #=> 5
print(lower_bound([], 3))                     #=> 0

B에서 x = 4, a[mid] = 4입니다. upper bound는 mid의 어느 쪽입니까?

mid까지는 답이 아닙니다. 따라서 ⑦은 ‘같을 때에도’ 오른쪽으로 이동합니다.

  • ①~⑦을 채운 뒤 [▶ 실행]과 [✔ 점검]을 누르십시오. A7 점검 통과가 나오면 완성입니다.
  • 실패하면 “내 결과 A, 정의대로 찾은 값 B” 형식의 메시지가 나옵니다.
  • x = 12, 4, 20에 대해 두 값을 먼저 예측한 뒤 실행하십시오.
  • 예측값과 실제값은 활동지 2부 A7에 기록하십시오.

DUP에 없는 4의 lower_bound와 upper_bound는 어떠합니까?

4 이상인 첫 칸과 4 초과인 첫 칸이 모두 5가 있는 4번 칸입니다.
