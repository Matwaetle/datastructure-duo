lower bound처음으로 x 이상이 나오는 자리
upper bound처음으로 x 초과가 나오는 자리
  • 둘 다 값이 아니라 칸 번호(인덱스)예요.

같은 B에서 x = 6이면 lower bound는?

6은 인덱스 3에 있고, 그 앞은 모두 6보다 작아요.

x = 6일 때 upper bound는?

6보다 큰 첫 값 9가 인덱스 4에 있어요.

  • [lo, hi) = lo 칸은 포함, hi 칸은 포함 안 함
  • 처음: lo = 0, hi = len(B) = 5
  • mid = (lo + hi) // 2 (// 는 몫)

B[mid] = 4 < 9. 처음으로 9 이상이 나오는 자리는 mid의 어느 쪽?

mid까지는 모두 9보다 작으니 답은 3번 칸 이후예요.

후보가 [3, 5)로 줄면 mid=4, B[4]=9 = x. 답은?

B[3]=6 < 9 이므로 mid 자신(4번)이 답이에요. 연습 편집기에서 lo, hi = 3, 5 로 바꿔 확인해 봐요.

N리스트 길이목표 비용비교를 몇 번쯤 하면 만족인지

코드를 쓰기 전에 계획 한 줄후보를 어떻게 줄일지 + 비교 몇 번쯤이면 만족인지

DUP[1, 3, 3, 3, 5, 7, 7, 9, 12, 12, 12, 12, 15]SORTED[2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
  1. ①②③ 범위와 반복
    lo, hi = ①, ②리스트 전체를 덮는 [lo, hi)
    while ③:후보가 하나라도 남은 동안
  2. ④⑤⑥ 갈림길 (lower_bound)
    ④ 답이 mid 오른쪽→lo = ⑤ mid는 답이 아님
    else→hi = ⑥ mid 자신이 답일 수 있음
  3. ⑦ upper_bound
    if ⑦: lo = mid + 1뼈대는 같고 ‘초과’에 맞게 비교만 다름
def lower_bound(a, x): ...   # 처음으로 x 이상인 자리, 없으면 len(a)
def upper_bound(a, x): ...   # 처음으로 x 초과인 자리, 없으면 len(a)

B = [2, 4, 4, 6, 9]
print(lower_bound(B, 4), upper_bound(B, 4))   #=> 1 3
print(lower_bound(B, 10))                     #=> 5
print(lower_bound([], 3))                     #=> 0

B에서 x = 4, a[mid] = 4. upper bound는 mid의 어느 쪽?

mid까지는 답이 아니에요. 그래서 ⑦은 ‘같을 때도’ 오른쪽으로 가요.

  • ①~⑦을 채우고 [▶ 실행] → [✔ 점검]. A7 점검 통과면 완성
  • 실패 메시지: “내 결과 A, 정의대로 찾은 값 B”
  • x = 12, 4, 20에서 두 값을 먼저 예측해 보고 실행해요.
  • 예측과 실제는 활동지 2부 A7에 적어요.

DUP에 없는 4의 lower_bound와 upper_bound는?

4 이상인 첫 칸과 4 초과인 첫 칸이 둘 다 5가 있는 4번이에요.
