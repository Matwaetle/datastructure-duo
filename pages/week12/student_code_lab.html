6은 인덱스 3에 있고, 그 앞의 값은 모두 6보다 작아요.

x = 6일 때 upper bound(인덱스)는 몇일까요?

6보다 큰 첫 값 9가 인덱스 4에 있어요.

  • 후보: 아직 답(경계 인덱스)일 가능성이 남아 있는 인덱스들
  • 후보 범위 [lo, hi): 인덱스 lo는 포함하고, 인덱스 hi는 포함하지 않는 범위
  • 처음에는 lo = 0, hi = len(B) = 5로 모든 칸이 후보예요.
  • mid = (lo + hi) // 2: 후보 범위의 가운데 인덱스 (// 는 나눗셈의 몫)

x = 9이고 B[mid] = 4 < 9예요. 처음으로 9 이상인 값의 인덱스는 mid를 기준으로 어느 쪽에 있을까요?

인덱스 mid까지의 값은 모두 9보다 작으므로, 답은 인덱스 3 이후에 있어요.

후보 범위가 [3, 5)로 줄면 mid=4이고, B[4]=9 = x예요. 답(lower bound)은 몇일까요?

B[3]=6 < 9 이므로 mid 자신(인덱스 4)이 답이에요. 연습 편집기에서 lo, hi = 3, 5 로 바꿔 실행해 확인해 보세요.
