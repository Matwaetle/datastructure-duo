step 0~3에서 lo, hi, mid는 어떻게 변합니까?

네 줄 모두 lo=0, hi=0, mid=0입니다. 범위가 줄지 않습니다.

def lower_bound(a, x):      # A7의 함수
    lo, hi = 0, len(a)      # 후보 범위 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo
