네 줄 모두 lo=0, hi=0, mid=0이에요. 탐색 범위가 줄지 않아요.

def lower_bound(a, x):      # A7의 함수
    lo, hi = 0, len(a)      # 후보 범위 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo
  • 후보 범위 [lo, hi): 아직 답일 수 있는 인덱스들. lo는 포함, hi는 포함하지 않아요.
