step 0~3에서 lo, hi, mid는?

네 줄 모두 lo=0, hi=0, mid=0. 범위가 안 줄어요.

def lower_bound(a, x):      # A7의 함수
    lo, hi = 0, len(a)      # 후보 범위 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo
  • 함수 이름 lower_bound_bad는 그대로 두기
