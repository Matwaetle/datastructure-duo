# 자료구조 활동지 (듀오링고식)

heback/datastructure 의 11~13주차 활동지를 한 화면에 한 걸음씩 푸는 화면으로 다시 만든 것.
답 칸과 원본 저장 스크립트는 그대로라서 제출 JSON 은 원본과 같다.

- 사이트: `docs/` (GitHub Pages)
- 만들기: 원본을 `../upstream/` 에 받아 두고 `python build.py`
- 검사: `node verify.mjs` — 원본과 제출 JSON 틀(키·라벨·타입 순서, 실제 저장 파일)을 비교
- 문구: `copy/` (원문 from / 새 문구 to), 지침 `COPY_GUIDE.md`, 합치기 `python merge_copy.py`
